# Devopsintelugu
The Microsoft Azure Fundamentals (AZ-900) certification is designed for individuals looking to demonstrate foundational knowledge of cloud services and how those services are provided with Microsoft Azure.

Here’s the topic-wise syllabus for AZ-900, organized according to the official Microsoft exam objectives (as of 2024–2025):

1. Describe Cloud Concepts (25–30%)
Benefits and considerations of using cloud services

	High availability, scalability, elasticity, agility, disaster recovery

	CapEx vs. OpEx

	Consumption-based model

	Cloud service types

	IaaS, PaaS, SaaS

	Shared responsibility model

	Cloud deployment models

	Public, Private, and Hybrid cloud

2. Describe Azure Architecture and Services (35–40%)
Core Azure architectural components

	Azure regions, region pairs, availability zones

	Resource groups, subscriptions, management groups

	Azure Resource Manager (ARM)

	Core Azure services and products

	Compute: VMs, Azure App Services, Azure Container Instances (ACI), Azure Kubernetes Service (AKS)

	Networking: Virtual Network, Load Balancer, VPN Gateway, ExpressRoute, DNS

	Storage: Blob Storage, Disk Storage, File Storage, Storage Tiers

	Databases: Azure SQL Database, Cosmos DB, Azure Database for MySQL/PostgreSQL

	Azure solutions

	IoT, Machine Learning, Azure Synapse Analytics, Azure DevOps, GitHub, Azure AI Services

	Management tools

	Azure Portal, Azure PowerShell, Azure CLI, Azure Resource Manager Templates, Azure Mobile App

3. Describe Azure Management and Governance (30–35%)
Cost management in Azure

	Pricing calculator, Total Cost of Ownership (TCO), Azure Cost Management, Service Level Agreements (SLAs)

	Azure governance features

	Azure Policy, Role-Based Access Control (RBAC), Resource Locks, Azure Blueprints, Tags

	Security and compliance

	Azure Security Center, Azure Defender, Key Vault, Microsoft Entra ID (formerly Azure AD)

	Multi-Factor Authentication (MFA), Conditional Access

	Monitoring and reporting

	Azure Monitor, Log Analytics, Azure Service Health
